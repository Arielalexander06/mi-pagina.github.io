Mi Portafolio Personal - Web Multipage

¡Hola! Soy Ariel Palma, estudiante de la Tecnología Superior en Desarrollo de Software en PUCE Tec. Este repositorio contiene mi portafolio personal y sitio web multipágina desarrollado desde cero aplicando buenas prácticas de HTML5 semántico y diseño web adaptativo.   

Estructura del Proyecto

El sitio web está organizado de manera modular utilizando una página principal en la raíz y subpáginas organizadas en un directorio dedicado:

mi-pagina.github.io/
│
├── index.html           # Página de bienvenida e inicio del sitio
├── pages/
│   ├── sobre_mi.html    # Sección de presentación, mapa de ubicación y habilidades
│   └── hobbies.html     # Sección de pasatiempos, deportes, equipos favoritos y clips
└── imgs/                # Carpeta centralizada de recursos visuales y logotipos

Tecnologías y Características Implementadas
HTML5 Semántico: Uso de etiquetas estructurales modernas para mejorar la accesibilidad y el SEO, tales como:

<main> para aislar el contenido principal de la página.

<figure> y <figcaption> para la correcta asociación de imágenes y pies de foto.

<time> para la representación semántica de fechas.

<progress> para representar de forma gráfica los niveles de habilidades y progreso de estudio.

<details> y <summary> para menús desplegables interactivos.

<dialog> para mensajes de bienvenida fijos.

Diseño y Multimedia:

Integración de mapas interactivos mediante <iframe>.

Inserción de videos multimedia de YouTube.

Enlaces de navegación interna optimizados con anclajes (#).

Despliegue: Configurado y alojado en vivo a través de GitHub Pages.

Secciones del Sitio

Inicio (index.html): Presentación general, menú de navegación principal hacia las demás secciones y enlaces directos a redes sociales.

Sobre Mí (pages/sobre_mi.html): Información biográfica, procedencia académica (Colegio Municipal Cotocollao y PUCE Tec), ubicación geográfica con Google Maps, esquema de habilidades duras y blandas con barras de progreso, metas profesionales y objetivos de estudio.

Hobbies y Deportes (pages/hobbies.html): Pasatiempo enfocado en la programación y desarrollo web, además de secciones dedicadas al baloncesto (Stephen Curry y los Golden State Warriors) y al fútbol (Real Madrid y Cristiano Ronaldo - CR7).
